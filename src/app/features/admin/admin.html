Panel de administración

Base del área reservada. El acceso se ha comprobado con la fila propia de public.user_roles; el rol no se lee de metadatos editables. La autorización real sigue en RLS y en servidor.

Sin CRUD todavía

Esta primera versión no permite crear, editar ni publicar cursos, bloques o lecciones. Tampoco hay subidas de vídeo, documentos ni operaciones de comercio.

No se muestran contadores, alumnos ni datos de ejemplo: no hay datos reales cargados.

La concesión del rol admin es manual y se hace desde servidor por una persona autorizada. No existe autoascenso ni formulario para asignarse el rol desde la aplicación.
